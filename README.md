# Score King

Compteur de points pour le jeu de cartes **Skull King** — application iOS (SwiftUI) et application web installable (PWA), hors-ligne, direction artistique pirate, bruitages rigolos et commentaires du Bosco.

> Application non officielle, non affiliée à Grandpa Beck's Games. Skull King est une marque de Grandpa Beck's Games.

**Ce dépôt est un cahier des charges prêt pour Claude Code** : voir `LANCEMENT.md`. L'agent remplacera ce README par les instructions de lancement des apps.

| Fichier | Contenu |
|---|---|

| `docs/01…07` | règles de score, spec fonctionnelle, DA, son & voix, architecture, tests, plan |
| `.claude/skills/` | 5 skills : calcul, DA pirate, son & voix, portes de qualité, revue visuelle |
